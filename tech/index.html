Why client-side matters

Most online tools ask you to upload your data to a server you do not control. A token, a password, a private document, or a chunk of source code goes somewhere else before you get a result back, and you have to trust that the service handles it properly and deletes it afterwards. The tools in this directory take a different approach: they run entirely in your browser. The work happens on your own device, in the page you opened, and nothing you type or paste is sent anywhere.

That matters most for the tools that deal with sensitive material. Decoding a JSON Web Token, generating a password, hashing a secret, or inspecting a file should never mean handing that material to a stranger. With a client-side tool, a token you decode never leaves your machine, a password you generate is never logged on a server, and a file you inspect is read by your own browser, not uploaded to be scanned somewhere else. Privacy here is not a policy promise — it is how the tools are built.

Running locally is also faster. There is no server round-trip, no queue, and no waiting for a response from a busy backend. Heavy work such as formatting a large JSON payload or parsing thousands of lines of recon output happens right in the page, and the result appears as soon as the work is done. It also means the tools keep working the same way whether you are on a fast connection or a slow one, because the processing does not depend on the network at all.

And because there is no server cost per use, there is no reason to charge for them. Every tool in this directory is free, with no account to create, no trial to expire, and no feature locked behind a payment step. That is the point: useful tools should be there when you need them, not gated behind a signup form.

How it works

How to use the tools

Every tool follows the same four steps, so once you have used one, you have used them all.

01

Pick a tool

Browse the directory below or filter by category to find the tool that fits the job, from decoding a token to building a sitemap.

02

Paste or enter your input

Type or paste your text, code, URL, or file into the tool. Most tools work with plain text input and need nothing else from you.

03

Run it in your browser

The tool processes your input locally on your own device. There is no upload, no waiting on a server, and no account to sign into.

04

Copy the result

Copy the formatted output, download the generated file, or use the result straight away in your project, report, or website.

Who they help

Who the tools are for

Built for the people who open a tool ten times a day and just need it to work.

Developers use these tools to format JSON, test a regex, convert a cURL command into code, compare two files, or turn a timestamp into a readable date — the small jobs that interrupt real work and should take seconds, not a signup flow. Because everything runs locally, even a large payload or a long file is handled without freezing the page.

SEO specialists and site owners use the sitemap builder, the robots.txt builder, the SEO analyzer, and the text analyzer to check the basics of a site before publishing: titles and descriptions, canonical tags, heading structure, word count, and crawler rules. These are checks worth doing on every page, and doing them in the browser means a draft or an unpublished page never has to be exposed to an external service to be reviewed.

Security researchers use the JWT studio, the CORS tester, the URL scanner, the hash generator, and the file inspector to examine tokens, headers, and files without sending the material under investigation to a third party. The report builder turns findings into a structured write-up with impact, reproduction steps, and remediation, ready to share with a team or a program.

Designers and businesses use the logo studio, the color studio, the contrast checker, the CSS generator, and the image tools to put together brand assets, check that text is readable, and prepare images for the web. A business owner who needs a QR code for a shop counter, a readable colour pair for a flyer, or a compressed image for a slow-loading homepage can do it here in a minute, free, without installing anything.
